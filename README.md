README
ชื่อโปรแกรม โปรแกรมนับจำนวนเลขคู่และเลขคี่ (Mini Challenge Even/Odd Counter)

Input
โปรแกรมรับข้อมูลจากผู้ใช้เป็น ตัวเลขจำนวนเต็ม 10 จำนวน โดยให้ผู้ใช้ป้อนค่าทีละตัวผ่านแป้นพิมพ์

Process
สร้างอาร์เรย์ (Array) สำหรับเก็บตัวเลขจำนวนเต็ม 10 จำนวน
รับค่าตัวเลขจากผู้ใช้ทีละตัว
ตรวจสอบว่าตัวเลขแต่ละตัวเป็นเลขคู่หรือเลขคี่ โดยใช้ตัวดำเนินการ % (Modulo)
หากหารด้วย 2 ลงตัว ให้เพิ่มจำนวนเลขคู่
หากหารด้วย 2 ไม่ลงตัว ให้เพิ่มจำนวนเลขคี่
เมื่อรับข้อมูลครบทั้ง 10 จำนวนแล้ว โปรแกรมจะแสดงผลรวมของจำนวนเลขคู่และเลขคี่
Output

โปรแกรมจะแสดงผลดังนี้

จำนวนเลขคู่ (Even count)
จำนวนเลขคี่ (Odd count)

ตัวอย่างผลลัพธ์

Enter number 1: 10
Enter number 2: 15
Enter number 3: 8
Enter number 4: 21
Enter number 5: 14
Enter number 6: 7
Enter number 7: 6
Enter number 8: 11
Enter number 9: 18
Enter number 10: 9

Even count = 5
Odd count = 5
วิธีรันโปรแกรม
บันทึกไฟล์ชื่อ MiniChallengeEvenOdd.java
เปิด Command Prompt หรือ Terminal
คอมไพล์โปรแกรมด้วยคำสั่ง
javac MiniChallengeEvenOdd.java
รันโปรแกรมด้วยคำสั่ง
java MiniChallengeEvenOdd
ป้อนตัวเลขจำนวนเต็มจำนวน 10 ค่า แล้วโปรแกรมจะแสดงจำนวนเลขคู่และเลขคี่
สิ่งที่ได้เรียนรู้
เรียนรู้การรับข้อมูลจากผู้ใช้ด้วย Scanner
เรียนรู้การใช้งาน Array เพื่อเก็บข้อมูลหลายค่า
เรียนรู้การใช้ for loop เพื่อวนรับข้อมูลหลายครั้ง
เรียนรู้การใช้ตัวดำเนินการ % (Modulo) เพื่อตรวจสอบเลขคู่และเลขคี่
เรียนรู้การใช้เงื่อนไข if-else เพื่อแยกประเภทข้อมูลและนับจำนวนแต่ละประเภท
