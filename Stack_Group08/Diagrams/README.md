# Diagrams

โฟลเดอร์นี้ใช้สำหรับจัดเก็บเอกสารและแผนภาพที่ใช้ในการออกแบบอัลกอริทึมของโครงงาน City Skyline: Next Greater Element

## ภายในโฟลเดอร์

### Pseudocode
เก็บ Pseudocode ของ Algorithm A: Brute Force และ Algorithm B: Monotonic Stack เพื่ออธิบายขั้นตอนการทำงานของอัลกอริทึมก่อนนำไปพัฒนาเป็นภาษา Java

### Flowchart
เก็บ Flowchart สำหรับแสดงลำดับการทำงานของโปรแกรมและอัลกอริทึม ได้แก่

- Flowchart A: Brute Force / Nested Loop
- Flowchart B: Monotonic Stack

### ClassDiagram
เก็บ Class Diagram ที่แสดงโครงสร้างคลาส ความสัมพันธ์ และเมธอดหลักของโปรแกรม Java
